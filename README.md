# Mathe-Trainer

Eine einfache Web-App zum Üben von Grundrechenarten.

## Funktionen

- Addition, Subtraktion, Multiplikation und Division
- Auswahl der gewünschten Rechenarten
- Einstellbare Höchstzahl für die Aufgaben
- Punktestand und Serie
- Auswahl der Klassenstufe (bestimmt Schwierigkeit und erlaubte Rechenarten, Klassen 1–6)

## Starten

### Mit Node.js

```bash
npm start
```

Dann im Browser `http://localhost:3000` öffnen.

### Oder direkt im Browser

Öffne einfach `index.html` im Browser.
